# NIPA SOLUCIONES

Aplicación web de diagnóstico rápido y seguimiento de equipos de cómputo.

## Ejecutar

Abrir `index.html` directamente en un navegador moderno. No requiere instalación ni servidor.

## Funciones iniciales

- Búsqueda y selección de 10 casos repetitivos.
- Diagnóstico con causa probable, protocolo de verificación y parámetros normales.
- Registro de equipos con modelo, serie, propietario y estado.
- Seguimiento de servicios e historial local.
- Persistencia con `localStorage` y exportación JSON.
- Interfaz adaptable para escritorio y móvil.

## Archivos

- `index.html`: estructura de la interfaz.
- `styles.css`: diseño responsive.
- `app.js`: datos, navegación y persistencia.
- `RESUMEN_PROYECTO.md`: contexto funcional y técnico.
- `AVANCE.md`: estado, decisiones y próxima tarea.
